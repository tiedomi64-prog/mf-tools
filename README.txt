MF TOOLS — installation

Contenu :
- index.html
- style.css
- app.js
- sw.js
- icon.svg
- manifest.json

Installation recommandée :
1. Décompresser le dossier.
2. Le publier sur un hébergement HTTPS (GitHub Pages, Netlify, Cloudflare Pages…).
3. Ouvrir l’URL dans Safari sur l’iPad.
4. Partager > Sur l’écran d’accueil.
5. Ouvrir MF Tools une première fois avec Internet.
6. Les données sont ensuite sauvegardées localement dans Safari.

Compatibilité :
- HTML/CSS/JavaScript sans framework.
- JavaScript volontairement simple pour ancien Safari/iOS 12.
- Service Worker pour cache hors-ligne lorsque Safari l’autorise.

Attention :
- Effacer les données de Safari peut supprimer les données locales de MF Tools.

Conseil iPad : dans Réglages > Safari, évite d'effacer les données du site MF Tools si tu veux conserver les checklists et contacts enregistrés.
